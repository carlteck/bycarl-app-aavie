# Mascotte AAVIE

Images détourées (fond transparent), mêmes poses que sur le site (`site_aavie/src/assets/mascotte`).
Chaque image existe en `@1x` (256 px au plus), `@2x` et `@3x` : `require('@/assets/images/mascotte/mascotte-accueil.png')`
choisit la bonne densité.

| Fichier                        | Pose                                                                    |
| ------------------------------ | ----------------------------------------------------------------------- |
| `mascotte-pointe`              | montre quelque chose à droite (contour blanc)                           |
| `mascotte-pointe-sans-contour` | même pose, sans contour blanc                                           |
| `mascotte-dossier`             | tient un dossier ouvert (coffre-fort, documents)                        |
| `mascotte-accueil`             | bras ouverts (accueil, état vide)                                       |
| `mascotte-pouce-leve`          | pouce levé (succès, confirmation)                                       |
| `mascotte-banniere.jpg`        | bannière 16:9 sur fond bleu nuit, non détourée (360 px de large en @1x) |

`mascotte-pouce-leve@3x.png` est légèrement agrandi (le personnage ne mesure que 630 px dans l'original).
